# CaseMate – Alpha Testing Checklist

## Purpose
This checklist is designed to help the team review CaseMate's core features, identify usability problems, and document issues before the Beta stage.

## Core Functionality
- [ ] Verify that CaseMate opens successfully.
- [ ] Check that the medical record upload area is accessible.
- [ ] Test uploading a sample medical record image or PDF.
- [ ] Check whether uploaded records display correctly.
- [ ] Review extracted medical information for accuracy.
- [ ] Check whether users can compare extracted information with the original record.
- [ ] Verify that errors or failed uploads are communicated clearly.

## User Experience
- [ ] Check whether the navigation is easy to understand.
- [ ] Review instructions and labels for clarity.
- [ ] Check whether the interface provides feedback after user actions.
- [ ] Identify confusing steps in the medical record workflow.

## Privacy and Safety
- [ ] Use synthetic or appropriately anonymized medical records for testing.
- [ ] Check that the interface does not expose sensitive information unnecessarily.
- [ ] Verify that AI-generated information is presented with appropriate limitations.

## Testing Notes
Record any bugs, unclear interactions, or incomplete features and share them with the team.
